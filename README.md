# Heart-Disease-Prediction
❤️ Heart Disease Prediction by Het

This project is a machine learning–based web application that predicts the risk of heart disease using patient health data. It uses a Logistic Regression model and a Streamlit interface to provide quick and easy predictions.

⸻

🔍 Overview

The application takes common clinical inputs such as age, cholesterol, blood pressure, and ECG results, and predicts whether a person is at low, moderate, or high risk of heart disease.
Along with the prediction, it also shows the risk probability (%) and simple observations based on the inputs.

⸻

🧠 Model Used
	•	Logistic Regression
	•	Chosen for its reliability, speed, and interpretability in medical datasets
	•	Outputs probability scores instead of just labels
  
🛠 Tech Stack
	•	Python
	•	Pandas, NumPy
	•	Scikit-learn
	•	Streamlit
	•	Joblib
